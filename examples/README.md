# Examples

`ai-proposals.example.json` illustrates valid **structure** for a model proposal, not verified findings. Evidence IDs are empty because real IDs must be obtained from the current analysis. The default pack uses `ACC-001`; if you select another pack or a subset of review areas, change `questionId` to an ID present in that review. Importing a proposal does not approve it.

For a real demonstration, serve the root directory and scan any public GitHub repository. Check GitHub API rate limits and disclose source coverage limitations. Do not share fabricated evidence as a real repository scan.

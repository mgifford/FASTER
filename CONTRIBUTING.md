# Contributing

The project is an experimental AGPL-3.0-only review assistant. Contributions should focus on reusable repository analysis, evidence provenance, accessible interaction, review-pack extensibility, and safe optional AI use.

- Open an issue describing the problem, expected behavior and evidence.
- Keep proposed changes small and testable. Run `npm run check` and report browser/assistive-technology validation when UI changes.
- Do not copy authoritative standard or questionnaire content without checking license and provenance. Pack contributions must state their source, status and version.
- Don't add hidden telemetry, paid-AI dependencies, automatic publication, automatic conformance determinations or arbitrary repository code execution.
- Code reviews should scrutinize untrusted input handling, DOM rendering, WebMCP tool boundaries and citation accuracy.

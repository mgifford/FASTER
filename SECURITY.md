# Security policy (starter)

This is an experimental client-side project and has not undergone a full security review. Do not use it to evaluate private repositories or sensitive documents until explicit permissions, authentication, isolation and privacy controls have been designed.

Do not report exploitable vulnerabilities publicly with live secrets or personal data. Contact maintainers privately using the repository's configured security advisory or private reporting mechanism once a maintainer repository exists. The template has no official support SLA. See `docs/SECURITY_AND_PRIVACY.md` for the threat model and implementation limitations.
